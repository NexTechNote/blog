About

Dev Notes is an automated weekly blog. Each week an AI agent drafts a post from a topic queue, opens a pull request for review, and — once merged — the site is built and published to GitHub Pages.

The site is a static Astro blog. The generator and workflows live alongside the content in the source repository.

How a post gets published

  1. A scheduled GitHub Action picks the next unused topic.
  2. An agent writes a Markdown post.
  3. A pull request is opened for review.
  4. Merging rebuilds and deploys the site.
