Welcome to Dev Notes

Oct 10, 2026 1 min read

  • #automation

This site is published automatically. Every week, an AI agent drafts a post from a topic queue, opens a pull request, and — once reviewed and merged — the post goes live here on GitHub Pages.

How it works

  1. A scheduled GitHub Action picks the next unused topic.
  2. The opencode agent writes a Markdown post.
  3. A pull request is opened for review.
  4. Merging publishes the site.

Stayed tuned for weekly posts on blogging, AI tools, and technical tutorials.
